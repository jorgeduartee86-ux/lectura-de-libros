# Historial de cambios

## 1.0.0 — 2026-08-31

- PWA React, Vite, TypeScript y Tailwind con tema literario claro/oscuro.
- Biblioteca local, búsqueda, filtros, progreso, notas, citas, autores y estadísticas.
- Auth invitada, relación de dos, consentimiento, PIN, recuperación y salida rápida.
- E2EE AES-GCM/HKDF, emparejamiento por fragmento URL y outbox cifrado.
- Conversación, señales, misma página, cartas, pregunta diaria, libro por turnos,
  ruleta, citas, recuerdos, universo y regalos.
- Supabase SQL, RLS, Realtime, Storage, Edge Functions y Web Push discreto.
- Vitest, Testing Library, Playwright, pgTAP, ESLint, Prettier y GitHub Actions.
